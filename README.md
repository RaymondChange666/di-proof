# DI Proof of Performance

DI is an autonomous crypto trading system. This repository records live trading performance — every trade, every incident, every version. No backtest-only results.

**First live execution: 2026-08-06**

## Structure

| Directory | Content |
|-----------|---------|
|  | Daily performance reports |
|  | Settled trade records |
|  | Rolling performance metrics |
|  | Incident history |

## Public Fields

- Date, equity, return
- Positions, trades (direction/reason/result)
- PF, Sharpe, max drawdown
- Incident count, system version
- Strategy in use

## Not Included

- Server details, API keys, private parameters
- Exact position sizes, wallet addresses
